==================================================
PRIMARY GOAL
==================================================

Build a reusable **Astra Arsenal / Codex system** that:

1. contains all current Astras in one authoritative data source
2. classifies every Astra by family and tags
3. defines what each Astra counters
4. defines what counters each Astra
5. supports hard counters
6. supports soft counters
7. supports transform interactions
8. displays this information in a clean in-game Codex / Arsenal UI
9. does NOT change actual combat behavior yet unless a tiny compatibility hook is needed
10. is designed so future combat logic can query the same database

The goal is to create one clean source of truth for current and future Astra interactions.
